# Request Proof Kit

**Target:** Q1 2027 · Planned

**Retire:** Copying the same confirmed request between intake tools and manually checking whether someone already owns it.

**Prove it:** Send one fictional request through two intake paths. The same confirmation key and unchanged request create one work item with both source events. Identical wording with two different keys creates two work items. A changed replay or missing confirmation never creates an extra task. A named test owner and a sample completion receipt make the outcome checkable.

Start with local examples, not live inboxes or a required AI subscription. Compare task counts and operator time against the current manual check.
